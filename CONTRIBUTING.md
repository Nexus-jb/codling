# Contributing to Codling

Thank you for helping. This page explains how we work.

## Language

Codling is developed in English. Code, identifiers, comments, commit messages,
pull request titles and descriptions, issues and documentation must all be in
English. The `Text policy` check enforces this on every push and pull request.

User interface translations are added by the maintainers only. The list of
accepted languages is kept in `scripts/check-text-policy.py`. Please open an
issue before you start any translation work.

## Before you start

- For anything larger than a small fix, open an issue first so we can agree on
  the approach.
- Keep each pull request focused on one change.
- Never commit secrets, signing keys or personal data.

## Pull requests

- Describe what changed and why, and how you tested it. Include the device, iOS
  version and jailbreak.
- All checks must pass before review.
- Features that touch the privileged helper, downloads or payments get an extra
  security review.
